# WunderLearn Frontend

## Project Overview
This is the frontend application for WunderLearn, an educational platform. Built with modern React and focused on providing an engaging landing page experience with smooth animations and responsive design.

## Tech Stack
- **Framework**: React 19.1.1
- **Build Tool**: Vite 7
- **Language**: TypeScript 5.8
- **Styling**: Tailwind CSS 4.1.13
- **Routing**: React Router 7
- **Animation**: Motion 12
- **Icons**: lucide-react
- **Linting**: Biome 2.2.3
- **Package Manager**: Bun

## Development

### Scripts
- `bun dev` - Start development server
- `bun build` - Build for production (runs TypeScript check then Vite build)
- `bun lint` - Run Biome linter with auto-fix
- `bun preview` - Preview production build

### Code Quality
- Uses **Biome** for linting and formatting (not ESLint/Prettier)
- **lint-staged** with Husky for pre-commit hooks
- Auto-formats on commit: `*.{js,ts,tsx,css,json}`

## Styling Guidelines
- Uses **Tailwind CSS v4** (latest version with @tailwindcss/vite plugin)
- Utility-first approach
- Components have `clsx` and `tailwind-merge` available for conditional classes
- Custom CSS in `src/index.css`

## Component Patterns
- Functional components with TypeScript
- Common components organized in separate folders with `index.tsx`
- Landing page sections are modular and self-contained
- Responsive design with separate Desktop/Mobile header components

## Git Workflow
- Main branch: `master`
- Uses conventional commits style

## Important Notes
- This is a **frontend-only** project
- Focus on user experience with animations and smooth transitions
- Mobile-responsive design is critical
- Uses Motion library for animations (not Framer Motion)
- Package manager is **Bun**, not npm or yarn

## Assets
- Public folder contains images and static assets

## When Working on This Project
1. Maintain component modularity
2. Follow existing patterns in Landing components
3. Test on both desktop and mobile viewports
4. Use Motion for animations, not inline transitions
5. Follow Biome's style rules (configured in biome.json)
